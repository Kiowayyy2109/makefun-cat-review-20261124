## The review

> One star. The food arrives late, the sunbeam moved without notice, and the human still expects me to acknowledge him. I will not.

A one-star review written by a house cat about its human: three grievances
escalating to a sunbeam relocation filed as a service failure, closed with
the driest possible deadpan — "I will not." Eight candidate lines were
drafted and scored against the brief (see `candidates.md`); this one won
for the clearest cat-only complaint. 129 characters, one line.

## How to run

```sh
python3 main.py
```

This writes the review (one line, 129 characters) to `/output/entry.txt`.
Python 3.13, standard library only, no network access, deterministic.
